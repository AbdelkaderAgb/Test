# ريلز المفروشات — نموذج تجريبي (UX فقط)

تطبيق أندرويد بسيط يعرض النموذج التفاعلي كاملاً داخل WebView.
بلا خادم، بلا دفع، بلا حسابات. كل البيانات والأسعار أمثلة.

## الشاشات
الريلز · صفحة المنتج · الطلب عبر واتساب · صفحة المتجر · التصفّح · دليل المتاجر حسب المدينة · كتالوج المنتجات · المحفوظات · حسابي
زر الرجوع في الهاتف يرجع بين الشاشات.

## طريقتان لاستخراج ملف APK

### 1) عبر GitHub بدون أي برامج (الأسهل)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد كما هو.
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**.
3. بعد 3–5 دقائق افتح التشغيل المكتمل ونزّل **furniture-reels-demo-apk**.
4. فك الضغط، انقل `app-release.apk` إلى الهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

### 2) عبر Android Studio
1. File ← Open ← اختر هذا المجلد.
2. Build ← Build App Bundle(s) / APK(s) ← Build APK(s).
3. الملف في `app/build/outputs/apk/`.

## تعديل الواجهة
كل الواجهة في ملف واحد: `app/src/main/assets/index.html`
يمكن فتحه في متصفح الكمبيوتر مباشرة لتجربة أي تعديل قبل بناء APK.
