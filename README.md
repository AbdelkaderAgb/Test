# ريلز المفروشات — نموذج قابل للاستخدام (v0.2)

تطبيق أندرويد خفيف (WebView) لتجربة فكرة «ريلز المفروشات» مع زبائن وتجار حقيقيين.
بلا خادم وبلا دفع: كل شيء يعمل على الهاتف.

## ما الجديد في v0.2
- **وضع التاجر**: حسابي ← وضع التاجر ← أضف منتجاً. صوّر أو اختر صوراً وفيديو من الهاتف، واكتب الاسم والسعر والقسم والوصف والألوان والمكونات.
  يظهر المنتج فوراً في الريلز (الفيديو يعمل تلقائياً) وفي الكتالوج والبحث وصفحة ديار. يُحفظ على الهاتف فقط.
- **أزرار حقيقية**: «اطلب عبر واتساب» يفتح واتساب برسالة جاهزة إلى رقم المتجر. «اتصال» يفتح الاتصال. «مشاركة» تفتح قائمة المشاركة في أندرويد.
- **اختيار المدينة عند أول فتح**، وتُحفظ الإعجابات والمحفوظات والمتابعات والمدينة.
- **معرض صور** في صفحة المنتج (اسحب يميناً ويساراً)، وتشغيل/إيقاف الفيديو بلمسة، وإعجاب بلمستين، وزر الصوت.
- **خط عربي مدمج** (IBM Plex Sans Arabic) يعمل بدون إنترنت.
- إعدادات: رقم واتساب لاستقبال طلبات المتاجر التجريبية، واسم متجرك، وإعادة ضبط النموذج.

## استخراج APK
يُبنى تلقائياً على GitHub عند كل push (تبويب Actions ← Build APK ← Artifacts).
أو من Android Studio: Build ← Build APK(s).

## تعديل الواجهة
1. عدّل `src/index.src.html`
2. شغّل `python3 src/build.py` (يدمج الخطوط وينتج `app/src/main/assets/index.html`)
3. افتح الملف الناتج في متصفح للتجربة، ثم ابنِ APK.

الخط: IBM Plex Sans Arabic — رخصة SIL Open Font License (من حزمة @fontsource على npm).
